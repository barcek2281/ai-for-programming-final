# VivaMind — ИИ-интервьюер (MVP)

Тесты проверяют запоминание и легко решаются с помощью ИИ. Устное интервью проверяет понимание, но у
преподавателя нет времени на каждого студента. **VivaMind** задаёт вопрос по материалам курса, затем
углубляющие вопросы по словам самого студента («почему?», «приведи пример», «а что если…»), оценивает
понимание по таксономии SOLO с цитатами-доказательствами — а итоговую оценку подтверждает преподаватель.

Направление экзамена *Pedagogy of Higher Education*: **Ethical assessment in the age of AI** + **Human–AI collaboration**.

---

## Запуск за 3 команды

Нужны Docker Desktop и ключ [OpenRouter](https://openrouter.ai/keys).

```bash
cp .env.example .env
```

Откройте `.env` и впишите `OPENROUTER_API_KEY=...` (остальное можно не трогать). Затем:

```bash
docker compose up -d --build
```

```bash
start http://localhost:8081
```

Первая сборка занимает несколько минут (скачиваются зависимости). Без ключа приложение тоже запускается,
но обработка PDF, генерация карточек и интервью будут отвечать ошибкой «OpenRouter отклонил ключ API».

### Демо-аккаунты

| Роль | Email | Пароль |
| --- | --- | --- |
| Преподаватель | `teacher@vivamind.local` | `SEED_DEMO_PASSWORD` из `.env` (по умолчанию `demo12345`) |
| Студент | `student@vivamind.local` | тот же |
| Администратор | `admin@vivamind.local` | `SEED_ADMIN_PASSWORD` из `.env` (по умолчанию `change-me`) |

Студенты могут регистрироваться сами. Преподавателей создаёт администратор на странице `/admin`.

Готовый сценарий показа и проверка критериев приёмки — в [docs/demo.md](docs/demo.md).
Учебные PDF для демо лежат в [docs/sample/](docs/sample/).

## Как это устроено

```
React SPA ──REST + JWT──▶ Spring Boot (монолит) ──▶ PostgreSQL 18 + pgvector
                                │                ──▶ SeaweedFS (S3 API) — исходные PDF
                                └──▶ OpenRouter: чат-модели и эмбеддинги (через Spring AI)
```

| Слой | Технология |
| --- | --- |
| Backend | Java 21, Spring Boot 4.1, Spring Security (JWT), Data JPA, Flyway, Maven |
| ИИ-слой | Spring AI 2.0: `ChatClient` + `.entity()`, `PgVectorStore`, `PagePdfDocumentReader`, `TokenTextSplitter` |
| Данные | PostgreSQL 18 + pgvector, SeaweedFS |
| Frontend | React 19, Vite, TypeScript, React Router, Tailwind CSS |

Код backend разложен по фичам в `backend/src/main/java/kz/vivamind/`:

| Пакет | Что внутри |
| --- | --- |
| `auth` | пользователи, роли, JWT, сид демо-аккаунтов |
| `course` | курс → темы курса → цели обучения |
| `material`, `rag` | загрузка PDF → фрагменты → эмбеддинги; поиск по материалам одной темы |
| `card` | карточки вопросов: генерация черновика, правка, утверждение |
| `exam` | экзамен по выбранным темам, код доступа |
| `interview` | цикл интервью; **`TurnPolicy`** — правила «углублять или закрыть вопрос» обычным Java-кодом |
| `grading` | оценка вопроса, проверка цитат, итоговый отчёт, расчёт балла, проверка преподавателем |
| `appeal` | апелляции |
| `ai` | все вызовы LLM (`AiService`) и сборка сообщений для модели (`AiMessages`) |
| `storage`, `speech`, `common` | S3, каркас голоса (фаза 2), ошибки и аудит вызовов LLM |

Системные промпты — в `backend/src/main/resources/prompts/*.st`, их можно править, не трогая код.

### Где человек, а где ИИ

| Делает ИИ | Делает человек |
| --- | --- |
| Пишет **черновик** карточки вопроса по материалам темы | Преподаватель правит и **утверждает** карточку — в экзамен попадают только утверждённые |
| Оценивает последний ответ и **предлагает** углубляющий вопрос | Решение «углублять или закрыть» принимает детерминированный `TurnPolicy` |
| Предлагает уровень SOLO с цитатами и уверенностью | Преподаватель видит транскрипт, может изменить уровень и **подтверждает итог** |
| Пишет текстовый отчёт: сильные стороны, пробелы, что перечитать | Балл считает формула (`ScoreCalculator`), не модель; апелляцию разбирает преподаватель |

### Честность и этика в коде

1. **Человек в контуре.** В режиме «Экзамен» итогового балла и отчёта нет, пока преподаватель не нажал «Подтвердить оценку» (`ReviewService.confirm`).
2. **Без AI-детекторов.** Защита — формат: углубления по словам студента, лимит времени, свой путь вопросов у каждого студента, блок вставки.
3. **Анонимизация.** В модель уходят только материалы курса и текст диалога. Всё, что отправляется, собирается в одном классе — `ai/AiMessages.java`; ФИО, email и ID там нет.
4. **Согласие.** Без `consent=true` сессия не создаётся; время согласия хранится (`interview_sessions.consent_at`).
5. **Прозрачность.** Студент видит рубрику до начала, а в отчёте — свой транскрипт, цитаты и пробелы.
6. **Защита от prompt injection.** Ответы студента обёрнуты в `<student_answer>`, в промптах — явный запрет выполнять инструкции из них, флаг `offTopicOrInjection` отправляет сессию на обязательную проверку.
7. **Цитаты проверяются.** `EvidenceValidator` удаляет цитаты, которых нет в ответах студента, и снижает уверенность.
8. **Сигналы, не доказательства.** Вставки, уходы со вкладки и таймауты показываются преподавателю отдельно и на балл автоматически не влияют.
9. **Логи.** Ответы студентов не пишутся в лог; в таблице `llm_calls` — только модель, токены и время.

## Настройки (`.env`)

| Переменная | Назначение |
| --- | --- |
| `OPENROUTER_API_KEY` | ключ OpenRouter — **обязательно для работы ИИ** |
| `LLM_FAST_MODEL` | быстрая модель: ход интервью |
| `LLM_STRONG_MODEL` | сильная модель: карточки, оценка ответа, отчёт |
| `EMBEDDING_MODEL`, `EMBEDDING_DIM` | эмбеддинги; по умолчанию `baai/bge-m3`, 1024 |
| `DB_*`, `S3_*` | PostgreSQL и SeaweedFS (для локального запуска менять не нужно) |
| `JWT_SECRET` | секрет подписи токенов — смените перед показом вне своего компьютера |
| `SEED_*` | администратор и демо-аккаунты |

Слаги чат-моделей в коде не зашиты — можно подставить любые с <https://openrouter.ai/models>.
Модель должна стабильно возвращать JSON. Перед реальным экзаменом прогоните 10 настоящих ответов на
казахском и русском и выберите модели окончательно.

После изменения `.env` перезапустите backend: `docker compose up -d --build backend`.

## Режим разработки

```bash
docker compose up -d postgres seaweedfs
```

Backend (нужен JDK 21; Maven ставить не надо — есть Maven Wrapper):

```bash
cd backend && ./mvnw spring-boot:run
```

Если сборка пишет `release version 21 not supported`, значит `JAVA_HOME` указывает на старый JDK.
В PowerShell: `$env:JAVA_HOME = "C:\Program Files\Java\jdk-21"`, затем `.\mvnw.cmd spring-boot:run`.

Frontend (Vite проксирует `/api` на `http://localhost:8080`):

```bash
cd frontend && npm install && npm run dev
```

Откройте <http://localhost:5173>. Backend сам читает `.env` из корня репозитория.

## Раскрытие использования ИИ

- Код проекта написан ИИ-агентом (Claude Fable 5.2, Claude Code) по техническому заданию команды; решения агента записаны в `docs/decisions.md`.
- Учебные конспекты в `docs/sample/` написаны ИИ специально для демонстрации. Для настоящего курса загружайте собственные материалы.
- Внутри продукта ИИ-модели (через OpenRouter) генерируют черновики карточек, углубляющие вопросы, черновик оценки и текст отчёта. Итоговую оценку подтверждает преподаватель.
